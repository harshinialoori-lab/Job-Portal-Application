# 💼 Job Portal Application Using Java

## 📌 Project Overview

The Job Portal Application is a simple Java-based project designed to connect job seekers with job opportunities. It allows users to explore available jobs, search for suitable positions, add new job listings, and submit job applications through a menu-driven interface.

This project demonstrates fundamental Java programming concepts and basic job management functionality.

## 🎯 Objectives

* Develop a simple job management application using Java.
* Implement job searching and listing functionality.
* Allow users to add new job opportunities.
* Enable job seekers to apply for available jobs.
* Practice object-oriented programming and collection handling.

## ✨ Features

* **View All Jobs:** Display available job listings.
* **Search Jobs:** Search for jobs by title or location.
* **Add New Jobs:** Add job details, including title, company, location, and salary.
* **Apply for Jobs:** Submit applications using the applicant's name and email.
* **View Applications:** Display submitted applications.
* **Interactive Menu:** Navigate through the application using a simple console menu.

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/java-job-portal.git
```

### Step 2: Open the Project

Open the downloaded project folder in Visual Studio Code.

### Step 3: Compile the Java File

Open the terminal in the project folder and execute:

```bash
javac JobPortal.java
```

### Step 4: Run the Application

```bash
java JobPortal
```
